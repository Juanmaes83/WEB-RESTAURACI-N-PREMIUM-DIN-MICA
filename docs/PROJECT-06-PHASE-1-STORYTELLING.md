# PROJECT 06 — PHASE 1 STORYTELLING / WOW PASS

Status: **IMPLEMENTED IN ISOLATED LAB / HUMAN REVIEW REQUIRED**

Branch: `feat/circular-dish-rotator-lab`

This phase raises the approved V2 wheel from a motion demo to a product-storytelling composition without changing the canonical engine.

## Scope implemented

### 1. Dynamic pizza story

Each of the eight selectable sectors now owns demo metadata:

- `name`
- `ingredients`
- `price`
- `descriptor`
- `mood`
- `headline lead`
- `headline tail`
- `accent`

The data is deliberately isolated in the LAB. Final restaurant-specific authoring belongs in Studio integration later.

### 2. Headline choreography

The selected product now drives a three-level editorial headline:

- overline / context;
- dynamic lead + pizza hero name;
- dynamic emotional tail.

The active pizza also drives the large background word, selection rail, mood line, descriptor and accessibility announcement.

### 3. Stronger hero sector

The active 45-degree sector still comes from a clipped duplicate of the same full-pizza source image. No independent Project 07 slice assets are used.

At rest the full pizza is slightly subordinated while the selected sector receives stronger lift, scale, brightness, saturation, local contrast, glow and aura. Final landing has a controlled overshoot before settling.

### 4. More theatrical Fortune-wheel Discover

`Discover` now has explicit phases:

1. anticipation / reverse wind-up;
2. multi-turn travel;
3. long deceleration through visible 45-degree ticks;
4. exact snap;
5. selected-slice reveal.

The final selection still derives only from `rotationProgress`.

### 5. Stronger copy-to-product relationship

The composition now includes an editorial visual bridge between copy and wheel plus a fixed selection beam terminating at the wheel. Product mood/accent follows the current selection.

## Invariants preserved

- one canonical `rotationProgress`;
- 45 degrees per sector;
- one complete pizza source image;
- fixed selector;
- direct circular drag;
- velocity-based flick;
- step navigation;
- reduced-motion selection path;
- no shared Studio/runtime/workflow files modified;
- no Project 07 independent slice assets used;
- no merge without Juanma + ChatGPT visual approval.

## Human review focus

Review these five questions:

1. Does the headline now feel connected to the selected pizza rather than like adjacent copy?
2. Does the active sector clearly become the hero without breaking the illusion of one complete pizza?
3. Does the ingredient/price/descriptor layer add value without making the composition busy?
4. Does Discover feel like a premium physical wheel: anticipation -> speed -> ticks -> deceleration -> reveal?
5. Is the visual bridge between editorial copy and selected sector strong enough for a real WOW moment?
