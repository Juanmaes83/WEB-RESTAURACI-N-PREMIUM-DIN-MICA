# Half Orbit — transparent dish assets

Carpeta de trabajo para imágenes de platos recortados, sin fondo, destinadas al motor Class 24 · Half Orbit Selector.

## Requisitos visuales
- PNG o WebP con transparencia real.
- Mismo plano, cámara, escala y encuadre entre variantes siempre que sea posible.
- Sin fondo añadido.
- Un plato por archivo.
- Evitar nombres genéricos repetidos.

Estas imágenes son assets del proyecto y se integrarán desde el Project State / motor correspondiente; esta carpeta no crea un segundo sistema de media.
