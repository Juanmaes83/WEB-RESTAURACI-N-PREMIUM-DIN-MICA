# assets/anchor-scenes/source

Drop the **real master scene photography** here — one closed image per product, each
already containing the hand, the object, the background and the light.

Requirements, so the swap reads as one continuous take:

- same canvas and pixel dimensions for every scene (the current runtime set is 1200x1500);
- same orientation;
- the hand in the same position, at the same camera distance, with the same light;
- the object inside the grip, never breaking the silhouette;
- consistent grade — `scripts/audit-anchor-scenes.mjs` allows a luma spread of 0.10.

Then point `dish.anchorScene.image` in `class4-config.js` at the file and register the
object's region in `anchorScene.hit` (fractions of the image). No engine change is needed.

Run `node scripts/audit-anchor-scenes.mjs` to validate the set: it fails with exit 1 if a
scene arrives misaligned, differently lit or differently framed.

The files currently in `runtime/` are an explicitly labelled **proxy** set generated by
`scripts/build-anchor-scenes.mjs` from the hand master plus the Project 01 food cut-outs.
They demonstrate the engine and the direction; they are not the final photography.
